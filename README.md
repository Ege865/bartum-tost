# Bartum Tost

Bartum Tost'un tanıtım sitesi. Astro + GSAP (ScrollTrigger, SplitText).

```bash
npm install
npm run dev      # yerel geliştirme
npm run build    # dist/ klasörüne statik çıktı
```

Yayın: `dist/` içeriği `gh-pages` dalına itilir, GitHub Pages oradan sunar.
Fotoğraflar: Bartum Tost ve Unsplash (Unsplash lisansı).
